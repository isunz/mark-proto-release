MARKPROTO 0.2.1

- 로그인 확인을 기다리지 않고 저장된 로컬 노트를 먼저 열도록 개선함.
- 새 페이지 제목 입력과 한글 조합 중 동기화가 포커스·편집기를 바꾸지 않도록 수정함.
- 페이지 클릭 즉시 선택·제목·아이콘을 표시하고 본문 로딩·실패 재시도를 제공함.
- 나머지 문서·첨부를 점진적으로 내려받으며 하단에 작은 진행 표시를 제공함.
- 로그아웃 시 기기 자료 보존·삭제를 선택함. 보존하면 로컬에서 계속 작성하고 같은 계정 로그인 후 동기화를 재개함.
- 하단 문구와 MARKPROTO를 본문 작업 영역의 양끝에 맞춤.

Windows는 NSIS 설치 파일 또는 앱 업데이트 버튼으로 설치함. macOS는 DMG의 앱을 응용 프로그램 폴더로 끌어다 놓아 대치함. Apple 인증·공증은 아직 적용하지 않음.

동기화에는 같은 서버 주소와 로그인 계정이 필요함. 로그아웃하며 자료를 지우면 미전송 변경은 복구할 수 없으므로 안내를 확인해야 함. 웹 서버는 자동 재시작하지 않음.
