# MARKPROTO 0.2.4

## 로컬 파일 편집 창 개선

- 파일 열기를 햄버거 메뉴의 파일 메뉴로 이동함. Ctrl/Cmd+O도 사용할 수 있음.
- 노트 화면과 구분되는 짙은 색 파일 편집 창을 적용함. 여러 파일은 탭으로 전환함.
- 제목줄 드래그로 이동, 가장자리로 크기 조절, 최대화·복구·X 닫기를 지원함. 제목줄을 두 번 눌러 최대화·복구할 수 있음.
- 저장·다른 이름으로 저장·노트로 복사에 SVG 아이콘을 적용함.
- 인코딩과 동기화 상태를 작은 하단 상태 바에 배치함. UTF-8 등의 인코딩 값을 눌러 선택할 수 있음.
- Windows 파일 경로의 내부 접두사를 제거해 읽기 쉽게 표시함.
- 창을 닫을 때 열려 있는 각 파일의 미저장 내용을 확인함. 외부 파일은 명시적으로 노트에 복사한 경우만 계정 동기화 대상이 됨.

Windows는 설치 파일 또는 앱의 업데이트 기능으로 설치함. macOS는 DMG의 앱을 응용 프로그램 폴더로 끌어다 놓아 대치함. macOS Apple 코드 서명·공증은 적용하지 않음.
