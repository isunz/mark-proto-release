MARKPROTO 0.2.2

- TXT·Markdown·SQL 등 텍스트 파일을 열거나 끌어놓아 원문을 편집할 수 있음.
- 원본 저장, 다른 이름으로 저장, 인코딩 선택, Markdown 미리보기와 노트로 복사를 제공함.
- 외부 파일은 자동 동기화하지 않으며, 노트로 복사할 때 현재 공간에 독립 문서를 만듦.
- 저장 중 추가 입력과 외부 프로그램의 파일 변경을 보호하고, 수정 중인 파일의 로컬 복구 사본을 보관함.
- 페이지를 제목 기반 파일명으로 Markdown 또는 일반 텍스트로 내보냄. 이미지가 있는 Markdown은 문서와 이미지가 들어 있는 ZIP으로 저장함.
- 설치 후 운영체제의 연결 프로그램에서 MARKPROTO를 선택할 수 있도록 텍스트 파일 형식을 등록함. 기본 앱 변경은 사용자가 선택함.

텍스트 편집은 파일당 2MiB까지 지원함. Markdown 미리보기·노트 복사는 기본 문법 범위를 지원하며 원문 저장에는 변환을 적용하지 않음. EUC-KR/CP949 파일은 읽기와 UTF-8 다른 이름 저장을 지원함.

Windows는 NSIS 설치 파일 또는 앱 업데이트로 설치함. Windows OS 코드 서명과 업데이트 파일 서명은 별개임. macOS는 DMG를 응용 프로그램 폴더에 끌어다 놓아 대치하며 Apple 공증은 적용하지 않음. 플랫폼별 채널은 실제 빌드·검증된 경우에만 갱신함.
